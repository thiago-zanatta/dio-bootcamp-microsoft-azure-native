# Bootcamp Microsoft Azure Native da Dio

## Descrição

Este repositório contém materiais e recursos utilizados no Bootcamp Microsoft Azure Native. O objetivo deste bootcamp é fornecer uma compreensão abrangente dos fundamentos da plataforma de aplicações no Azure, abordando desde os conceitos básicos de computação em nuvem até os serviços avançados oferecidos pela plataforma.

## Conteúdo do Bootcamp

### Fundamentos da Computação em Nuvem

- Modelos de computação em nuvem
- Capex vs Opex
- Benefícios da computação em nuvem
- Tipos de serviço: IaaS, PaaS, SaaS
- Modelo de responsabilidade compartilhada

### Arquitetura do Azure

- Regiões e zonas de disponibilidade
- Regiões soberanas (EUA e China)
- Recursos do Azure
- Assinaturas e grupos de gerenciamento

### Serviços de Computação

- Máquinas Virtuais (VMs)
- Serviço de Aplicativos (App Service)
- Serviço de Redes (VNET)
- Contêineres e Serviço de Kubernetes (AKS)
- Área de Trabalho Virtual (Virtual Desktop)
- Azure Functions

### Armazenamento no Azure

- Contas de armazenamento
- Redundância: LRS, ZRS, GRS, GZRS
- Serviços de Blob, Disco, Filas, Arquivos e Tabelas
- Camadas de acesso: Hot, Cold, Archive
- Azure Data Box para migração de grandes volumes de dados

## Estrutura do Repositório

- `docs/`: Documentação e materiais de referência
- `scripts/`: Scripts utilizados durante o bootcamp
- `examples/`: Exemplos de código e aplicações
- `labs/`: Laboratórios práticos para reforçar o aprendizado

## Como Contribuir

1. Faça um fork deste repositório.
2. Crie uma nova branch: `git checkout -b minha-nova-feature`
3. Faça suas alterações e commit: `git commit -m 'Adiciona nova feature'`
4. Envie para o repositório remoto: `git push origin minha-nova-feature`
5. Abra um Pull Request
